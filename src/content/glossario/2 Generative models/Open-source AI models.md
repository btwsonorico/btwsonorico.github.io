question: "What defines an open-source AI model?"
answers:
  - "Its code is publicly available"
  - "It is always free to run at scale"
  - "Its training data is always public"
---
These are models where the underlying source code is publicly available and distributed freely among the community, favoring transparency and accessibility. Furthermore, open-source models offer significant flexibility, as users can make specific adaptations to suit their unique requirements by acting on the accessible code.

- Utilizing open-source models grants full control over deployment, allowing to host models on-premises or on private clouds and maintain strict data governance. It also requires architecting your own solution. The inference engine to run the model must be implemented (for instance, using libraries like Ollama), together with managing the necessary optimizations
- New features offered in commercial tools are often rapidly replicated as open-source implementations by the community

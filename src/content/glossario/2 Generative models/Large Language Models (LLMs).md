A Large Language Model is a common foundation model for text generation. They are a type of deep learning model trained on immense amounts of data, making it able to understand and generate natural language to perform a wide range of tasks. These LLMs are built on a type of neural network architecture called a “transformer” which excels at handling sequences of words and capturing patterns in text. Some useful facts to better understand LLMs:

- An LLM works as a giant statistical prediction machine, which repeatedly predicts the next word in a sequence. They learn patterns from their training data and generate content that follows those patterns.
- LLMs represent a major leap in how humans interact with technology, as they are the first AI system that can handle unstructured human language at scale, allowing for natural communication with machines, by capturing context, nuances and reasoning.
- While the core of an LLM is text prediction, modern commercial systems basically act as a reasoning engine capable of using external tools and functions. Through a mechanism called “Tool calling” (or function calling), the LLM is able to reason and recognize when it needs help, triggering code execution for data analysis or math, instructing specialized image generation models to create visuals, or search the web when it is missing critical information.

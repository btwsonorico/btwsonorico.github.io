answers:
  - "How relevant each part of the input is"
  - "How much memory the model has left"
  - "How long the final answer should be"
---
A mechanism that lets a model weigh how relevant each part of its input is to the part it is processing. In "the cat sat because it was tired", attention can link "it" to "cat". It is the central operation of a transformer.

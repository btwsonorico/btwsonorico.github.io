A meta prompt, also called a system prompt, is a set of instructions provided to the AI model behind the scenes before user interaction begins. These instructions may be hidden from the user. Meta prompts set behavior, tone, or boundaries for how the AI should respond (e.g. You are a helpful assistant)

- System prompts in the Commercial Models (ChatGPT Web) and System Prompts in the API models are different, hence why users may experience differences in quality and output. Some companies, such as Anthropic, periodically make their system prompt public, in order to be transparent to users and give out good practices in guard-railing and setting behaviors.

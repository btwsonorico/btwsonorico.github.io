RAG is an AI framework for enabling LLMs to retrieve facts from an external knowledge base. Vector databases are key to supporting RAG implementations. RAG helps ensure that a model is linked to the most current and reliable facts, and that the users have access to the sources so that its claims can be verified. “Grounding” the LLM in trusted data can help reduce model hallucinations and provide reliable answers.

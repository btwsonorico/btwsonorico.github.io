- **Patterns written once** as a shared spec with design tokens, then reused in every tool.
- **Step wizards that resume** from the server, with a guard on unsaved changes.
- **Pages that recover by themselves** after an error, instead of showing the framework's error.
- **One vocabulary**: the same word for the same thing everywhere in the interface.
- **Prototype first**, then code; and a 3D force graph for this site.

- **GitHub Spec Kit** with one shared preset: the same principles in every project, changed in one place.
- **As-built specs.** Each requirement has a status (done, partial, missing) with a pointer to the code; gaps become tasks.
- **Generic foundations** (auth, jobs, feedback, telemetry, UI) written once, with a short section for each project.
- **Lessons promoted** to principles, patterns or rules when they hold beyond one project.

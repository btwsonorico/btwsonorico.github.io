# Portfolio

Sito statico con Astro, pubblicato su GitHub Pages dal workflow `.github/workflows/deploy.yml`.

- `src/content/scritti/`: un file Markdown per ogni essay, pensiero o nota di lettura.
- `src/pages/`: home, pagina di ogni testo, feed RSS.
- `src/scripts/oggetto.ts`: l'oggetto 3D in wireframe (Three.js).
- `public/`: file copiati così come sono (CV in PDF, immagini).

Comandi: `npm run dev` (anteprima), `npm run build` (sito in `dist/`).
